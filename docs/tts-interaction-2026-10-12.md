# 朗读起点与阅读位置的交互

调查日期：2026-10-12。区分「眼睛正在看的位置」「耳朵正在听的位置」与「上次保存的听读位置」，不把它们合并成一个游标。

## 官方产品依据

| 产品 | 已核实的行为 | 对本插件的启发 |
| --- | --- | --- |
| [Readest](https://www.readest.com/docs/listen) | 从当前段落启动；选文朗读到选区结束即停止；小播放器展开后切音色/倍速 | 当前上下文优先；选文与连续阅读分开 |
| [Readwise Reader](https://docs.readwise.io/reader/docs/faqs/text-to-speech) | 从屏幕中部附近段落启动；暂停保留位置，停止则隐藏播放器并需重新定位；用户滚动后停止自动跟随，提供 return / jump | 采用当前阅读点和返回听读处；本插件额外持久保存停止后的位置，满足用户明确要求 |
| [Apple Books](https://help.apple.com/itc/booksassetguide/en.lproj/itcd68191c9b.html) | 带配套朗读音轨的书从当前页开始，可设置自动翻页 | 页面是清晰起点；此文档是 media-overlay 配套音轨，不能外推为所有电子书的通用TTS |
| [NaturalReader 扩展](https://help.naturalreaders.com/en/articles/6093937-reading-webpages-chrome-extension) | 播放后点击正文可改变起点；Highlight to Read / Read Selection 只读选文 | 显式指向正文位置的意图优先，不能偷偷跳回历史 |
| [PocketBook](https://pocketbook.ch/en-ch/news/pocketbook-audio-ch) | 官方介绍明确从同一阅读页切换为TTS | 眼读转听读应尽量没有位置跳跃；该来源为2022年产品说明，不用来推断最新全部控件 |

## 本插件的规则

1. 首次听这本书：从当前可见页/段落开始。
2. 暂停后点主播放键：继续当前会话，不因为用户临时查资料而偷偷重设听读点。
3. 关闭播放器再打开，保存的句子仍在当前页：主播放键继续保存的句子，不重复页首。
4. 关闭后翻到新页/新章：主播放键从当前页开始；第一层同时提供「继续上次朗读」与「从当前页朗读」，不用进设置。
5. 只读选文：只读选区并停止，不覆盖整本书的听读书签。
6. 正在听时翻页查阅：暂停自动跟随，音频继续当前章；提供「回到朗读处」与「从当前页朗读」。回到朗读处只移动页面；从当前页则重置音频起点。
7. 查阅状态读到章末：先暂停，主播放键为「继续下一章」。本版依赖同一阅读引擎加载下一章，不能为了预读强行换掉用户查看的页面；确认继续后才打开下一章。
8. 换音色/试听：保留听读位置与倍速，试听后恢复暂停状态，不自动继续付费正文。
9. 重开书/重启插件：每书保存CFI；PDF保存页码+片段偏移。文件修改后不盲用旧锚点；无效锚点提供从当前页重新开始。
10. 跨设备、删除/重命名、重排版本的复杂锚点迁移不在本版承诺内。普通播放位置按句/片段保存，不宣称音频秒级同步。

## 界面约束

平时保持用户选择的五控件极简浮条。只有存在恢复/换起点的实际分歧时显示一行文字操作，不用确认弹窗。常用服务/模型/音色/试听在展开层；密钥、地址等配置在明确的「配置服务」入口。倍速与焦点可见，不增加悬浮提示。

后续可评估：点选段落后「从此处连续朗读」（与只读选文区别）、睡眠定时、语言自动切声、独立后台章节队列、离线音频。它们是调研候选，不是本版已实现功能。
