# 书库操作与首次打开修复

书库索引与原文件分开管理。卡片菜单提供「从书库移除」和单独放在底部的「删除原文件…」。移除只持久保存可见性，保留进度、划线、朗读位置、封面与阅读笔记；提示提供撤销。也可在 Obsidian 文件菜单中再次选择「用图书阅读器打开」重新加入。首页继续阅读和图书命令忽略已移除项；恢复已开的阅读标签不代表重新加入。

删除原文件需要确认，显示仓库内具体路径、按 Obsidian 回收站设置处理、清除进度与划线、保留阅读笔记和仓库外文件。确认默认聚焦取消。只有真正删除源文件才清理阅读数据；划线清理也写入磁盘，避免刷新后复现旧记录，同时不改写阅读笔记。

首次 Markdown 打开问题在复用后台阅读标签时可复现：打开流程先等待正文加载，排版又需要标签可见，导致首屏停在原标签、下一次点击才加载。改为发起视图切换后立即激活标签，再等待加载结束；保留 `file` 与旧 `path` 状态兼容，并处理延迟加载标签。不注册 Markdown 为默认文件视图。

验证（2026-10-13）：461 项 Node 测试、4 项 Python 测试、源码 ESLint、9 种语言字典、标准和社区构建检查。新增测试覆盖多格式移除/重新加入、保存失败回滚、隐藏项续读、目录重命名、删除确认与失败、磁盘划线清理及隐藏标签等待布局。

macOS 隔离仓库通过真实卡片/菜单验证：移除保留源内容、进度、划线与笔记；撤销恢复；取消删除；恢复标签仍不重新加入；确认删除仅移除测试书，保留笔记和仓库外测试原文。首次点击复用后台标签后已渲染 GFM 表格，第二次打开仍为阅读器，普通 Markdown 保持原生编辑器。第一次删除测试在关闭引擎标签时记录过宿主 ResizeObserver 通知警告；最终首次打开和移除/撤销复测无错误。Windows 和手机未做真机验证。

设计参考：[Apple Books 的移除与删除区别](https://support.apple.com/en-ca/guide/books/ibks67184a3a/mac)。发布仍需最终 SHA 的官方预扫描、草稿资产安装验收和公开下载核对；预扫描通过不等于正式商店审核完成。
