# Official listing refresh — 4.9.4

## Short description (133/200)

## Long description (897/1000)

Read EPUB, PDF, MOBI, FB2, comics, Markdown, TXT and HTML in Obsidian. Start with six public-domain classics or discover books through Hacker Books rankings, topics and reading lists. Highlight passages, add comments and keep Markdown notes linked back to the source. Ask optional AI about selected text, a page or a text-based PDF; customise quick prompts and save replies as notes. Translate words and passages, build a vocabulary note and review with Spaced Repetition or Anki. Listen aloud with device or optional cloud voices. Desktop users can import selected Calibre books and send books over Wi-Fi to a paired, jailbroken Kindle. Reading and annotations work offline. Online AI, public catalogs and cloud speech need a connection; some providers charge separately. CLI AI and Kindle transfer are desktop-only. Scanned PDFs need an existing text layer for text search and AI text questions.
