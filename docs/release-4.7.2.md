# 4.7.2 密钥获取入口

参考独立仓库 Qiaomu Audio 的 `src/core/cloud-services.js` 与 `src/obsidian/settings-tab.js`，为 Reader 现有云端朗读服务补上「获取密钥」和「服务文档」。入口放在密钥输入旁，使用现有描述文字样式和原生链接，未增加 hover tooltip。兼容服务显示获取说明；本地与免密钥服务没有此入口。MiniMax 的帮助跟随国内／国际端点切换。

本次只整合 Reader 使用的朗读服务帮助，不引入 Audio 的转写引擎或配置，不共享两个插件的密钥与数据。

## 本次验证

- 463 项 Node 测试通过；其中两个新增 UI 用例覆盖七个服务、切换与端点编辑、中英文标签、兼容与免密钥服务、帮助链接不包含密钥、渲染不触发合成。
- 4 项 Python 本地语音测试通过；i18n、ESLint 零警告、标准构建及社区构建通过。
- 标准 `main.js` 为 5,199,582 字节，社区包为 5,199,583 字节；两者通过现有 5,200,000 字节预算与发版资产检查。
- 在 GitHub 读取确认：此前 TTS PR #60 已合入，4.7.1 三个发布文件与主分支文件摘要一致；官方 Obsidian 索引正确指向 `joeseesun/qiaomu-reader`。远端 manifest、versions 声明均为 4.7.1，最低 Obsidian 1.11.4。
