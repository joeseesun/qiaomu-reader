# 4.9.1 书库可靠性验收

核对日期：2026-10-26。基线为已公开的 4.9.0。原开发目录有其他工作，修复在独立分支完成。

## 用户可见变化

- 默认按最近添加排序；可切换最近阅读、书名。中文书名使用拼音排序规则，导入时间有记录，既有图书退回文件创建时间。
- 下载位置固定为用户指定的下载目录，否则使用已配置书库目录，再否则为 `Books`。不再根据哪个文件夹书最多来猜位置。下载目录也纳入书架展示范围。
- 优先使用下载候选或本地容器元数据命名，缺元数据时清理文件名中的 Z-Library 标记，兼容 Windows 保留名。未改名既有书籍，避免破坏链接。
- SHA-256 精确查重：同内容提示已有并复用；不同内容同名书保留为独立文件。并发导入串行处理，避免同时导入两份相同文件。摘要按文件大小与修改时间失效，改名保留导入记录。
- 新封面缓存为最大 240×360 的独立 JPEG，不再把原图 base64 不断写进单个 JSON。旧缓存逐张迁移，原文件保留用于恢复。超过 120 本时书架只渲染可见范围与少量预加载行；继续阅读入口和键盘导航保留。
- 乔木 Home 按需回读独立封面文件，插件重启后不依赖旧的 base64 内存缓存；不读取书籍正文。
- MOBI/AZW3 的未标注类型封面根据图片头补 MIME 类型。

## 封面来源与边界

乔木书库后端目前通过 Z-Library Telegram bot 搜索和取得电子书。当前搜索解析只读取候选文字，返回书名、作者、格式等字段，没有把源站封面传给客户端；Open Library 作品匹配是补充封面来源。因此，仅放宽前端 URL 检查不会得到中文书封面。本次没有接入未经核实的源站封面 URL，也没有更改后端认证或下载链路。

本地书架优先使用书籍内嵌封面。本轮用原创 EPUB 经 Calibre 生成的 MOBI，在真实 Obsidian 提取到 1200×1800 的原内嵌 JPEG，再生成 240×360 缩略图。对照中未标注 MIME 的同一图片也能解码，所以 MIME 缺失不是已证实的用户原文件故障原因；仍需失败的原 MOBI 复现，不能宣称修复所有 MOBI。

## 10 月 26 日：书目、已有提示与统一找书

- 下载候选与书内元数据合并保存书名、作者、年份、语言、ISBN、出版社及来源；Calibre 导入也保存作者并进入同一书目层。临时搜索 ID、授权码、令牌和设备 ID 不进入记录。
- 书架显示元数据书名与作者，书架搜索支持作者、ISBN、年份和语言，书名排序使用书目标题。旧文件仍可按原文件名搜索。
- 乔木书库结果匹配本地书目与当前设备可查询的 Calibre：有效 ISBN（兼容 ISBN-10/13）或稳定来源 ID 表示准确匹配；仅书名和作者一致表示“可能已有”，保留下载选择。文件尚未同步或已移除时显示曾下载，不声称本地已有。
- 普通 vault 文件 `Qiaomu Reader/Book records/<sha256>.md` 保存每本书的书目与完成任务 ID。每书独立写入，保留用户正文与未知字段，拒绝覆盖较新 schema。启动和 metadataCache 变更读取记录，重命名跟随书籍；同步读入的摘要不会直接冒充当前文件摘要缓存。
- 单个“找书”入口、单个查询框：默认本地与 Calibre，切换乔木书库或公开书源时保留查询词。输入本地查询不会访问在线书源；公开书源搜索不再自动打开两个浏览器标签。高级 Calibre 导入窗口沿用查询词。
- 书目记录自动创建，新增流程不强制创建阅读笔记；既有阅读笔记自动创建设置保留。默认找书界面可展开最近保存的书目记录。
- 保留原有 4.8 MB 单资产门槛；完整项目 GPL 文本移到同包 styles.css，并加入完整文本校验，main.js 保留许可证声明、归属和位置说明。

- 清空插件书目缓存并重新加载，实际从 Markdown 恢复作者、年份、ISBN 和完成任务记录；通过原生文件重命名，记录路径随之更新。并非两台真实设备或 Obsidian Sync 服务联调。
- 新增作者行后，重新验证 3,000 本长短书名及有/无作者混排：挂载 20–35 张卡片，行高一致，最后索引 2999 可达，Home/End 焦点正确。
- 原生测试库原插件、数据和受限模式已恢复，临时书籍及新增书目记录已删除；日常 rockfish 未修改。
- 历史下载只剩文件名且没有书目记录时，不会伪造已丢失的作者/年份。后续重新导入可读取容器元数据，精确重复文件复用并补写记录；旧本地任务 ID 没有可恢复的书目关联，仍保留原本机记录。
- Markdown 需要随 vault 正常同步；它不提供跨设备事务锁。Calibre 仅查询当前设备可访问的库，未连接不等于没有该书。Windows/手机真机验证仍未完成。
