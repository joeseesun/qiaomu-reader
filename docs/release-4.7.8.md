# 4.7.8 — Windows 本地语音模型安装修复

合入贡献者 yato369 的 PR #68。模型压缩包中的子目录始终以 POSIX `/` 匹配文件清单，修复 Windows 完整下载后因路径分隔符不一致而解压失败的问题。

保留清单、文件大小、SHA256、路径穿越和符号链接检查。已有校验通过的下载缓存会复用；升级后再次安装即可补齐缺失文件，不需要主动删除缓存。

验证：479 项 Node 测试、6 项 Python 测试、八种语言检查、ESLint、标准构建和发布资产核验在 macOS 通过。新增 Windows CI 运行完整 Python 安装/下载回归，包括嵌套文件、拒绝越界及符号链接、断点续传、校验失败、残留安装恢复和缓存复用。Windows CI 结果、官方扫描、隔离安装与公开资产回读在发布时独立核对。

未在 Windows 物理设备重新下载真实大模型或合成语音；贡献者的实机结果见原 PR，不将其冒充本次验证。无设置或用户数据迁移。
