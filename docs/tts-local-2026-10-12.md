# 本地语音与 macOS 原生语音接入方案

状态：2026-10-12，Mac 原生语音已在候选分支实现并通过当前 Mac 的真实 Obsidian QA；本地模型安装器仍为设计。没有下载模型、修改系统语音设置，也没有做本地模型音质/性能测试。现有 OpenAI-compatible 输入框不能代表这些模型的安装、音色管理和克隆能力已经接入。

## 可行性与运行时

| 选项 | 已核实的入口 | 产品处理 |
| --- | --- | --- |
| F5-TTS | [官方项目](https://github.com/SWivid/F5-TTS/tree/d852486451313ab31924303f6120e1aa19a208ce)有 Apple Silicon 安装说明；[独立 MLX 实现](https://github.com/lucasnewman/f5-tts-mlx/tree/85d015f62b7c6e37311a484c915effb7cf95ccaa)支持参考音频、对应文字与量化 | Mac 可选 MLX 后端；固定模型及后端版本。不能把独立 MLX 包与官方 F5 v1 权重任意组合 |
| Spark-TTS | [官方实现](https://github.com/SparkAudio/Spark-TTS/tree/2f1ea9082400547242641f5271b6f941c9f439d1)支持中英、声音克隆及声音属性控制；[MLX-Audio](https://github.com/Blaizzy/mlx-audio/tree/e66ad2ff4eb96ce1149000187b30370cbcd707aa)列出 `mlx-community/Spark-TTS-0.5B-bf16` | Apple Silicon 优先验证 MLX；0.5B 不等于整个运行环境的内存占用，也不能据此承诺 M4 实时 |
| IndexTTS2 | [官方推理代码](https://github.com/index-tts/index-tts/blob/d9e41aac89fd00b3d71497fddb287b7f24613712/indextts/infer_v2.py)有 MPS 自动检测；[CLI v2](https://github.com/index-tts/index-tts/blob/d9e41aac89fd00b3d71497fddb287b7f24613712/docs/cli_v2_usage.md)提供 init/download/check/synth/batch，支持参考音频和情感配置 | 先核验官方 MPS 路径，Mac 不启用 CUDA/DeepSpeed 参数；MLX-Audio 存在 indextts 模块，但未验证其与所选 IndexTTS2 权重、情感参数完全兼容 |
| macOS 原生语音 | [AVSpeechSynthesizer](https://developer.apple.com/documentation/avfaudio/avspeechsynthesizer/)、[speechVoices](https://developer.apple.com/documentation/avfaudio/avspeechsynthesisvoice/speechvoices())、[quality](https://developer.apple.com/documentation/avfaudio/avspeechsynthesisvoice/quality) | 自动识别系统，枚举真实已安装音色及品质；无需模拟 Option+Esc。缺少高品质音色时引导系统下载，再刷新 |

补充候选为 Qwen3-TTS 与 Kokoro：MLX-Audio 已列出相应模型。是否放入推荐列表，以同机中文长文、启动延迟、峰值内存和稳定性测试决定，不按模型名推断音质。上述代码许可与模型权重许可分别保存到安装清单；例如 F5 官方预训练权重为 CC-BY-NC，而其代码为 MIT。IndexTTS 使用项目自己的模型使用协议。

## macOS 实机发现

同一台 Mac、同一次核验：Obsidian 的 `speechSynthesis.getVoices()` 返回 180 个音色；原生 `AVSpeechSynthesisVoice.speechVoices()` 返回 190 个。原生列表额外出现中文「声音2」「声音4」，quality 为 enhanced，当前 Obsidian 列表没有它们。某个 identifier 含 premium，但 API quality 仍为 enhanced，界面必须使用实际属性。

进一步在 macOS 27.0.1、Apple Silicon 上验证：Apple 的 Swift 解释器能枚举并合成这些增强声音，但相同代码编译为独立程序后看不到 Siri 音色。维护者 [siri-say](https://github.com/marcomontalbano/siri-say/tree/60c2b5f45c8fe15621933f0e5fa4033f021b4ac5) 也记录了宿主签名造成的可见性差异。Apple 在 [WWDC 2020](https://developer.apple.com/videos/play/wwdc2020/10022/) 曾明确说 Siri 声音不通过公共 API 提供；本次观察不代表 Apple 对所有系统、所有程序承诺开放。

候选使用系统自带 `/usr/bin/osascript -l JavaScript` 作为宿主，通过 JXA 调用公共 AVSpeech API。无需 Xcode、Python 或额外助手；不调用私有 SiriTTSService，也不模拟快捷键或向其他应用发送 Apple Events。脚本内容固定，文字及临时路径通过 stdin JSON 传递；取消只终止本次合成子进程。Node 模块在 Mac 桌面判断后用 CommonJS `require` 加载，Obsidian 的浏览器式 `import('node:…')` 实测无法加载。

真实 QA：191 个选项（自动选择及 190 个音色），增强「声音2」「声音4」分别实际播放 3.351 / 3.272 秒的测试音频；音频播放时间推进、试听后恢复原段及倍速且不改选择、关闭试听停止、四段书籍连续播放、关闭再开续读均通过。原生 API 生成音频而非独立直出，让通用播放器控制暂停和倍速。参考接口：[write(_:toBufferCallback:)](https://developer.apple.com/documentation/avfaudio/avspeechsynthesizer/write(_:tobuffercallback:))。

合成临时 WAV 在系统临时目录的独占子目录，校验实际 PCM 帧数并重建完整 WAV 头，成功、失败和取消均清理；最终音频进入现有有界内存缓存。系统管理音色文件，插件不复制到 vault。不承诺每台 Mac 都有相同增强声音：以本机枚举及试听为准。整机断网、其他 macOS 版本、锁屏和长期后台运行尚未验证。Kyoko 是日语，本机没有枚举到 Otoya；不能硬编码它们作为中文推荐。

另在真实 QA 中合成 150ms 后取消：确认当时存在一个本次临时目录，取消后一秒目录已清理，控制器保持 idle，无迟到播放或错误。424 项测试、ESLint、i18n 与标准/社区构建通过；新增 CommonJS 产物测试验证原生模块只在桌面加载，避免源码 ESM 测试漏掉实际宿主差异。证据仅覆盖当前 Mac 与指定 QA 库，候选未公开发布。

## Windows 与手机的兼容边界

播放器、句子断点、试听恢复与云端协议共用；按平台和运行时检测暴露适用选项，不用系统名称推断接口已可用。

| 平台 | 当前候选 | 后续本地能力与验证边界 |
| --- | --- | --- |
| Mac 桌面 | Edge、云端、Web Speech、Mac 原生语音；原生已实测 | 增强声音依赖系统可见性；MLX 本地模型安装器待实现 |
| Windows 桌面 | Edge、云端及宿主实际提供的 Web Speech；隐藏 Mac 入口 | 如 Web Speech 不足，单独适配 WinRT；不能沿用 JXA 或 MLX。无 Windows 真机证据 |
| iPhone / iPad | 云端及运行时存在的 Web Speech；隐藏 Edge 桌面直连和 Mac 原生入口 | Obsidian JS 插件不能直接增加 Swift 原生模块；未验证后台、锁屏及系统全部增强声音 |
| Android | 云端；检测 Web Speech，缺失时提供直接配置入口 | 原生 TTS 需宿主暴露接口或另做可配对助手。当前没有 Android 原生桥或手机真机证据 |

[Obsidian 官方文档](https://docs.obsidian.md/Plugins/Getting%20started/Mobile%20development) 明确手机没有 Node/Electron。仅 Android 系统有 [TextToSpeech / Voice](https://developer.android.com/reference/android/speech/tts/Voice) 不等于 Obsidian WebView 可以调用；该接口还能区分声音质量与是否需要网络。[LocalTTSReader](https://community.obsidian.md/plugins/local-tts-reader) 的维护者记录了其 Android WebView 缺少 speechSynthesis、采用可选助手的方案，这属于对方设备上的证据，不替代本项目实测。

Windows 的 [WinRT SpeechSynthesizer](https://learn.microsoft.com/en-us/uwp/api/windows.media.speechsynthesis.speechsynthesizer) 提供 AllVoices、Voice 和文本转音频流；只接受已安装的 Microsoft 签名声音。Narrator 能使用自然音色，不代表那些声音一定出现在 WinRT 或 Chromium 列表里，必须枚举及合成验证。

同步来的不适用 provider 保留选择并显示「选择其他语音服务」，不静默改成付费服务；本机声音缺失则要求重选。云端账号可跨设备，密钥按本机 SecretStorage 可用性配置。手机的 `127.0.0.1` 指手机自身，不能连接电脑模型；使用电脑服务需要可达的 HTTPS 端点，本候选不提供公网发布、局域网配对或隧道安装。

移动端模型下载目前不提供：未来若做，应由原生助手保存在其应用私有目录并处理平台备份/清理规则，不能把桌面 Python/MLX 方案或模型文件同步进 vault。WASM 模型也是独立性能方案，需先验证内存、首段延迟、持久存储和后台行为，不能当作免费实时能力已经具备。

## 用户操作

1. 从播放器的音色面板进入「语音设置」，选择「本地模型」。已有服务选择不重置，仍保留用户指定的桌面默认 Edge。
2. 首次检查芯片、系统、可用内存/磁盘及已有运行环境。每个模型显示实际下载大小、适用语言、运行条件与「下载并启用」；未核实的体积不编造，兼容性未实测的明确标记。
3. 点击后安装隔离运行环境、下载固定版本资源，分别显示进度，可取消/重试。支持选择已有模型目录。安装位置在用户应用数据目录，模型与参考音频不进入 Obsidian vault 同步。
4. 下载完成仍是「待验证」。启动本地服务、检查模型文件、合成一条短句并验证音频后才显示「可用」。失败给出具体修复操作，保留已完成的下载。
5. 在播放器直接切换已就绪模型与保存的音色、逐个试听。安装和高级维护收在设置；缺少音色时，面板直接显示「添加音色」。

音色按模型能力处理：固定音色显示真实列表；克隆音色由参考音频及必要的对应文字组成一个可命名档案。F5 MLX 的示例使用约 5–10 秒、单声道 24kHz 音频，这只是该后端的输入建议，不统一套给所有模型。音频转换由本地服务执行，原文件不改动。保存自己的或获授权使用的参考音频后，反复选用时无需重新上传。试听不覆盖书籍断点，结束后恢复原段落暂停。

## 接口边界

插件负责阅读定位、播放、断点与设置；独立本地运行时负责模型安装、合成及进程管理。不把 Python、模型权重或推理循环打进插件主线程，也不要求安装另一个无关产品才能阅读。桌面本地安装与手机远程连接是不同能力。

MLX-Audio 当前服务器已有 `GET /v1/models`、`POST /v1/audio/speech`、`GET /v1/audio/voices?model=…`，speech 支持 `ref_audio`、`ref_text`。但仍不能直接假定通用适配器满足全部需求：

- `/v1/models` 不是完整的安装/下载状态机。
- 音色目录枚举 `voices/*.safetensors`，没有这类文件的克隆模型可能返回空列表；不能据此判定无可用音色。
- `ref_audio` 是服务端文件路径，手机/远程服务不能直接使用插件机器上的绝对路径，需要上传并返回服务端标识。
- F5 MLX 是独立项目，目前没有发现 MLX-Audio 的 F5 模块，需要单独适配或统一包装。
- 官方 IndexTTS2 CLI 单次运行会初始化模型，不能每读一句就重启命令；连续阅读需要常驻工作进程并串行处理。

拟定本地管理接口：环境状态、模型清单、安装任务/取消、启动/停止、音色档案、合成/取消。后端能力须显式返回是否有固定音色、是否要求参考文字、是否支持情感/流式。只绑定本机回环地址并校验访问凭据；如未来开放局域网，另做明确设置。执行安装命令使用固定参数数组，不拼接用户文本；固定版本、验证下载完整性，失败不留下「已就绪」假状态。

## 存储与生命周期约定

用户明确要求模型不得放入 Obsidian 插件目录。约束覆盖整个 vault：模型权重、Python/uv 环境、下载残片、合成音频缓存、安装日志、参考音频均不放在 `.obsidian/plugins/` 或库内其他目录，不通过库内软链接绕过。插件目录只保留插件分发文件及现有轻量配置/阅读断点。模型和运行环境按操作系统用户共享于不同 vault，无需每个库重新安装。

macOS 建议布局（拟实现，不表示已创建）：

```text
~/Library/Application Support/qiaomu-reader/tts/
  models/        固定版本模型资源，含托管的 HF hub 存储
  runtimes/      按后端及版本隔离的 Python/本地运行时
  voices/        用户导入的参考音频、转写及音色档案
  state/         模型登记、设备配置、安装事务与版本关系

~/Library/Caches/qiaomu-reader/tts/
  audio/         可重建音频缓存，受容量与过期时间约束
  downloads/     可恢复下载的临时资源
  packages/      可重建的安装包缓存

~/Library/Logs/qiaomu-reader/tts/  有数量/容量上限的诊断日志
```

持久模型放 Application Support 是为了保留用户主动下载的离线能力；Caches 可以清理，不能把它作为模型唯一安装位置。可重新下载的大文件在平台支持时设置排除备份属性并验证；用户自建音色不可自动按缓存清理。路径通过平台 API/目录库获取，不拼用户名。Windows 使用当前用户 LocalAppData，Linux 按 XDG 分别放 data/config/state/cache；不占用系统级目录或要求管理员权限。依据：[Apple 文件存储指南](https://developer.apple.com/documentation/foundation/using-the-file-system-effectively)、[XDG 规范](https://specifications.freedesktop.org/basedir/latest/)。

模型设置只展示「占用空间」「更改位置」「使用已有模型」「清理缓存」「移除模型」。默认路径放高级区域，可在 Finder 中打开。用户可以选择非同步目录或外接盘：检查可写、剩余空间和真实路径；禁止选中已知 vault 内路径，识别符号链接，已知云盘路径给出说明。不能承诺识别任意第三方同步目录。外接盘未挂载时显示「连接模型所在磁盘」，不悄悄重新下载到系统盘。

- **设备配置与同步**：绝对路径、进程信息、安装就绪状态和本地服务凭据保存在库外设备配置；vault 只引用模型/音色的逻辑标识。换电脑同步后重新探测，无资源时显示「本机未安装」，不把另一台电脑的 available 状态沿用。用户主动导出的音频/音色备份属于单独导出操作。
- **共享与所有权**：托管模型按后端、模型 ID、精确 revision、量化规格登记；多个 vault 共用同一份，使用安装锁和进程间协调。用户选择已有 HF 缓存或模型目录时，登记为外部资源，默认只读引用，不复制，也不接管删除。HF 的 blobs/snapshots 去重机制可复用；托管缓存用显式 `cache_dir` 或仅对子进程设置缓存变量，不改用户 shell 或全局 HF 配置。[HF 缓存依据](https://huggingface.co/docs/huggingface_hub/guides/manage-cache)
- **下载与升级**：提前核算剩余下载、解压和保留旧版所需空间。暂存、验证文件及版本、完成后切换登记；跨磁盘迁移先复制验证，不能假装 rename 可跨盘原子提交。失败保留旧版可用，取消不删除已完成的共享模型。未完成资源不暴露为 ready。
- **删除边界**：清理缓存只清可重建资源；移除模型先确认依赖/使用中的会话及可释放空间，只删本产品明确托管的文件，不清用户全局 HF 缓存。卸载 Obsidian 插件不会自动删除库外模型、运行时或音色；提供独立的本地资源管理/卸载入口，完整卸载前列明这些数据。删除自定义音色需单独确认，不和模型卸载捆绑。
- **进程生命周期**：首次播放按需启动，一个用户一个受协调的本地服务；并发请求排队。关闭一个 vault 仅释放其会话，不杀掉其他库正在使用的服务。空闲卸载模型内存并按策略退出；不默认开机启动。
- **系统音色**：Apple 管理其安装目录与下载，插件仅枚举和调用，不复制、移动或删除系统声音文件。

## 上线前证据

每个承诺支持的模型/系统组合需实测：干净环境安装、已有安装复用、下载中断恢复、冷启动、中文与中英混排合成、切音色、停止后无迟到音频、长文连续播放、内存回收。记录首段等待和生成耗时/音频时长，才能判断是否适合边生成边阅读。Mac 原生桥另验增强音色的实际生成。未完成前不添加看似可用但无法工作的模型按钮。
