01 / 阅读

你的书，终于和笔记在一起。

EPUB 自由排版，PDF 保留原页与图表。调好字体、字号和纸面颜色，继续上次的位置；也可以从内置的六本中英文经典开始。

EPUB · PDF · TXT · Markdown · HTML，两个版本均支持

02 / 划线与笔记

划下一句话，留住一个想法。

选中文字就能划线、批注。每本书关联一篇 Markdown 阅读笔记，原文与自己的理解留在一起。以后点一下来源链接，还能回到书中继续读。

笔记是可编辑的 Markdown 文件

03 / AI 伴读

看不懂的地方，接着问。

选中一段话，请 AI 解释概念、举例或梳理逻辑。正文就在旁边，讨论不用来回复制；Obsidian 版还能把完整回答保存或追加到阅读笔记。

AI 按需启用，需连接你选择的服务；截图对话为界面演示

04 / 查词与朗读

读外文，也可以从容一点。

Obsidian 版划词查词、段落翻译，收录生词时一并保留原句和来源。两个版本都支持语音朗读，让眼睛休息一下，也能继续读下去。

DSH 查词使用宿主原生会话；语音能力随版本与环境不同

Obsidian 版

  1. 打开官方插件页，点击 Add to Obsidian。
  2. 在 Obsidian 中完成安装 → 启用。
  3. 点击左侧书库图标，打开一本内置书。
打开官方插件页
浏览器没有唤起 Obsidian？

在 Obsidian 中打开「设置 → 第三方插件 → 浏览」，搜索 Qiaomu Reader，确认作者为「向阳乔木」，安装并启用。需要 Obsidian 1.11.4 或更高版本。

手动下载最新版本 ↗

DeepSeek Harness 版

  1. 从 Release 下载 .tgz 安装包与 SHA256SUMS。
  2. 按安装说明校验文件，添加到你的 profile。
  3. 重载 profile，打开侧栏的「乔木阅读」。
下载安装包
查看 DSH 安装命令与兼容说明

在下载目录校验文件，然后将路径与 YOUR_PROFILE 换成实际值：

shasum -a 256 -c SHA256SUMS
dsh plugin --profile YOUR_PROFILE add /absolute/path/qiaomu-reader-dsh-1.1.2.tgz

macOS 桌面版使用应用自带 CLI。详细路径和步骤见安装说明。Windows/Linux、实体手机未验证；0.2.2 alpha 尚不声明支持。DSH 版暂不提供 Kindle 传书、乔木书库激活及 MOBI / FB2 / 漫画支持。

开始之前，你可能还想知道

几个简单的回答。

免费吗？需要先配置 AI 吗？

插件免费开源，采用 GPL-3.0 许可。阅读、划线与笔记无需 AI。AI 使用你选择的服务，相关账号、服务可用性与费用由服务方决定。

没有电子书，也能试吗？

可以。首次打开书库即可体验六本内置中英文经典，包括《道德经》《唐诗三百首》《世说新语》与三本英文经典，也能添加自己的图书。请使用有权阅读的文件。

笔记和图书放在哪里？

Obsidian 版保存在当前仓库，DSH 版保存在宿主工作目录的乔木阅读文件夹。阅读笔记采用 Markdown，可继续编辑与备份。两个版本不自动互相同步。

PDF 扫描件也能问 AI 吗？

PDF 会保留原页。文本选择、搜索和基于文字的问答需要可靠的文字层；扫描页可阅读，不承诺自动识别图片中的文字。

手机能用吗？

Obsidian 版可从手机端社区插件市场安装；本机 CLI、Calibre 和 Kindle 传书仅限桌面。DSH 版暂未完成实体手机和平板验收。

需要的时候，怎样升级或反馈？

Obsidian 在设置 → 第三方插件 → 检查更新；DSH 版从 Release 获取新包并重载 profile。问题可提交到各版本 GitHub Issues，附上版本号、操作步骤与报错。
